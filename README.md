# Retail SQL Assessment

## Project Overview
This project focuses on analyzing retail data using **SQL Server**. It includes data cleaning, database creation, sales analysis, and business insights.

## Technologies Used
- SQL Server
- SQL
- Power BI

## Key Activities
- Created relational database tables.
- Cleaned and standardized retail data.
- Removed duplicate records.
- Analyzed sales and product returns.
- Compared regional and store performance.
- Generated business insights and recommendations.

## Conclusion
This project demonstrates the use of SQL for retail data management, analysis, and business decision-making.
